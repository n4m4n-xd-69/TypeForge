You are the lead product manager and game systems designer for TypeForge.

IMPORTANT:
Do NOT implement anything yet.

Your task is to deeply inspect the existing TypeForge/Keystroke codebase and create a complete, production-grade PRD for a new core game mode called:

TYPEFORGE: SHADOW BATTLE

This game will become a major feature inside the existing TypeForge typing platform.

==================================================
1. EXISTING PRODUCT CONTEXT
==================================================

TypeForge is a typing-performance platform that currently includes:
- Typing practice
- Code/template typing practice
- Competitive typing
- Battle/battlefield concepts
- User profiles
- Statistics
- Leaderboards
- Progression/gamification

The new game must NOT feel like a separate unrelated game.

It should feel like a natural extension of TypeForge:

TYPING SKILL → COMBAT ACTION → DAMAGE → VICTORY

The game should make typing speed and accuracy directly control the player's combat performance.

==================================================
2. GAME CONCEPT
==================================================

Create a 2-player typing-driven combat game inspired by:
- Stickman fighting games
- Shadow ninja characters
- Minimal silhouette fighters
- Fast competitive arena combat
- Futuristic arcade combat

DO NOT copy any existing game's characters, artwork, names, mechanics, or branding.

Create an original TypeForge visual and gameplay identity.

Core concept:

Two players control shadow-style fighters.

Instead of manually controlling every attack with traditional game controls, players perform attacks, blocks, combos, dodges, and special moves by correctly typing generated words/text.

The better and faster the player types:
- The faster they attack
- The stronger their attacks become
- The more combos they can perform
- The more effectively they defend
- The more energy they generate
- The more special abilities they can activate

The game must make typing itself feel like combat.

3. GAME MODES
==================================================

Design the PRD for these modes:

A. PLAY WITH FRIEND

- Player can copy the invite code.
- Player can copy an invite link.
- Player can share the link.
- Second player joins using the code/link.
- Host can see opponent joined.
- Host starts the match.

B. RANDOM MATCH
- Player chooses "Find Opponent".

- Define matchmaking states:

  - Opponent found
  - Connecting
  - Ready
  - Countdown
  - Battle

D. PLAY VS BOT
Create a single-player mode.

Player can fight an AI bot.

Include multiple bot difficulties:
- Easy
- Normal
- Hard
- Expert
- optionally Adaptive

Define how bot performance is generated.

The bot should simulate:

- Accuracy

- Combo behavior

Do NOT make the bot feel artificially perfect.
